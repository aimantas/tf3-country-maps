# Deutschland: Germany island map for Transport Fever 3

Install
1. Copy `map-kit/heightmaps/*` into the `heightmaps` folder and `map-kit/towns_industries/*` into the `towns_industries` folder of your Transport Fever 3 userdata folder (`Steam/userdata/<your id>/3493540/local`).
2. In the game: Map Editor, new map, Temperate, Very Large, 1:1. Pick the German names if you like.
3. Import the heightmap `Deutschland_4097_playable.png` with minimum -12, maximum 180 and water level 0. Press Return after typing each number.
4. Import the towns `Deutschland_60_towns_starter_industries`. If a file called `request` is listed, don't pick it.
5. Connect your towns, save the map and start a game.
